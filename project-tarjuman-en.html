TARJUMAN

A digital platform designed to connect organizations participating in international events with qualified Saudi language experts. The platform supports expert search, account approval, requests, evaluation, complaints, and deposit-based booking workflows.

Local Prototype (Localhost) — Not Publicly Hosted
ARENFRES

Project Idea

TARJUMAN addresses the need for a structured way to connect organizations involved in international events with qualified Saudi language experts based on language, specialty, city, and evaluation.

Platform Users

  • System Administrator
  • Organization Employee
  • Language Expert
  • Evaluation Entity

Key Features

  • Account approval and profile management.
  • Expert search by language, specialty, city, and rating.
  • Evaluation and complaint workflows.
  • Deposit payment with a 24-hour payment window.
  • Request tracking between organizations and experts.

System Analysis

The project included requirements analysis, workflow definition, user roles, database modeling, and interface design to create a complete digital service flow.
