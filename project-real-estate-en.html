DATA ANALYSIS · 2025

Saudi Real Estate Deals Analysis

A data-analysis project focused on Q1 2025 real-estate transactions. I cleaned and organized the dataset, analyzed key dimensions, and built an interactive Power BI dashboard for comparing regions, property categories, prices, and transaction values.

View Data File ↗Watch Dashboard Video ↗

Objective

Transform raw real-estate transaction data into a clear visual view that supports comparisons between regions and helps communicate transaction volume, categories, pricing, and time-based patterns.

What I Did

  1. Reviewed the dataset and identified the fields needed for analysis.
  2. Cleaned and standardized the data in Excel.
  3. Prepared the dataset for analysis and visualization.
  4. Built indicators, filters, and comparisons in Power BI.
  5. Designed an interactive dashboard for region, month, property category, and price analysis.

Outcome

The final dashboard presents total transactions, selected-region information, detailed records, geographic distribution, and value comparisons between regions.
